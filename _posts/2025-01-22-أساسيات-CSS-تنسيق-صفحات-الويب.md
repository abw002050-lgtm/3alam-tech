CSS (Cascading Style Sheets) هي اللغة التي تجعل المواقع جميلة. بدونها تكون صفحات HTML مجرد نصوص بيضاء بلا أي تنسيق.

## لماذا نحتاج CSS؟

تخيّل موقعًا بدون ألوان، بدون خطوط مرتّبة، بدون تصميم متجاوب على الهاتف — هذا ما يكون عليه HTML وحده. CSS هي الحل.

## طريقة كتابة CSS

```css
/* المُحدِّد (Selector) + الخاصية (Property) + القيمة (Value) */
p {
  color: #333;
  font-size: 16px;
  line-height: 1.8;
}
```

## ثلاث طرق لإضافة CSS

1. **مضمن (Inline)** — يُضاف مباشرة على العنصر (غير موصى به)
2. **داخلي (Internal)** — داخل وسم `<style>` في الصفحة
3. **خارجي (External)** — في ملف `.css` مستقل (الأفضل)

```html
<!-- الطريقة المثلى -->
<link rel="stylesheet" href="style.css">
```

## أهم الخصائص

| الخاصية | الوظيفة |
|---------|---------|
| `color` | لون النص |
| `background` | خلفية العنصر |
| `font-family` | نوع الخط |
| `margin` / `padding` | الهوامش الخارجية / الداخلية |
| `border` | الحدود |
| `display` | طريقة العرض (`flex`, `grid`, `block`...) |

## التنسيق المتجاوب (Responsive)

الهدف: الموقع يظهر بشكل جيد على الهاتف والحاسوب معًا.

```css
/* الحاوية الرئيسية */
.container {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto;
}

/* على الهاتف */
@media (max-width: 768px) {
  .container {
    width: 100%;
    padding: 0 15px;
  }
}
```

## Flexbox: التخطيط الحديث

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}
```

`flex` يجعل ترتيب العناصر أفقيًا أسهل بكثير من الطرق القديمة.

## CSS Variables: المتغيّرات

```css
:root {
  --primary: #2563eb;
  --text: #1f2937;
  --bg: #ffffff;
}

body {
  color: var(--text);
  background: var(--bg);
}

a {
  color: var(--primary);
}
```

المتغيّرات تُسهّل تغيير الألوان لاحقًا في مكان واحد.

## نصائح عملية

- استخدم خطوطًا عربية واضحة مثل `Cairo` أو `Tajawal` من Google Fonts
- اجعل التباين (Contrast) بين النص والخلفية كافيًا للقراءة
- اختبر موقعك على مقاسات شاشة مختلفة
- ابدأ بـ Mobile First: صمّم للهاتف أولًا ثم وسّع للحاسوب

## ما بعد CSS؟

CSS الحديثة فيها الكثير: `Grid`, `Animations`, `Transitions`, `clamp()`. سنتعمّق فيها في شروحات قادمة.
