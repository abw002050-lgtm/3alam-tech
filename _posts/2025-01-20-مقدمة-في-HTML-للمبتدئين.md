HTML (HyperText Markup Language) هي اللبنة الأساسية لأي موقع على الإنترنت. في هذا الشرح سنتعلّم أساسياتها بأسلوب مبسّط.

## ما هي HTML؟

HTML ليست لغة برمجة بالمعنى الحرفي، بل هي **لغة ترميز** (Markup Language) تُستخدم لبناء هيكل صفحات الويب. تتكوّن من一组 من العناصر (Elements) تُحاط بالوسوم (Tags).

> كل ما تراه على الإنترنت — النصوص، الصور، الروابط، الجداول — يبدأ بـ HTML.

## بنية صفحة HTML الكاملة

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحبًا بالعالم!</h1>
  <p>هذه أول فقرة في صفحتي.</p>
</body>
</html>
```

## أهم الوسوم الأساسية

| الوسم | الاستخدام |
|-------|-----------|
| `<h1>` إلى `<h6>` | العناوين بدرجات مختلفة |
| `<p>` | فقرة نصية |
| `<a href="...">` | رابط تشعّبي |
| `<img src="..." alt="...">` | صورة |
| `<ul>` / `<ol>` | قائمة غير مرقّمة / مرقّمة |
| `<div>` | حاوية (Container) |
| `<span>` | حاوية مضمنة (Inline) |

## مثال عملي: صفحة تعريفية بسيطة

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي</title>
</head>
<body>
  <h1>عاصم محمد</h1>
  <p>مطوّر ومؤسس <strong>عالم تقني</strong>.</p>

  <h2>مهاراتي</h2>
  <ul>
    <li>HTML و CSS</li>
    <li>JavaScript</li>
    <li>تطوير الويب</li>
  </ul>

  <a href="https://wa.me/00967735383729">راسلني على واتساب</a>
</body>
</html>
```

## نصائح مهمة للمبتدئين

- استخدم دائمًا `lang="ar"` و `dir="rtl"` للصفحات العربية
- أضِف `alt` لكل صورة لتحسين إتاحة الوصول (Accessibility) و SEO
- استخدم العناوين بترتيب منطقي: `h1` ثم `h2` ثم `h3`
- لا تنسَ `<meta charset="UTF-8">` لدعم العربية

## الخطوة التالية

بعد أن تتقن HTML، ستنتقل إلى **CSS** لتنسيق الصفحات وإضافة الألوان والتصميم الجميل.
