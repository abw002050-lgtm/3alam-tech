Python هي أسهل لغة برمجة للمبتدئين، وفي الوقت نفسها من أكثر اللغات طلبًا في سوق العمل.

## لماذا Python؟

- **بسيطة** — أقرب للغة الإنجليزية من اللغات الأخرى
- **قوية** — تُستخدم في Google, Instagram, Netflix
- **متعدّدة الاستخدامات** — ويب، ذكاء اصطناعي، تحليل بيانات، أتمتة
- **مجتمع كبير** — مكتبات لكل شيء
- **مطلوبة في الوظائف** — من أعلى اللغات راتبًا

## أول كود Python

```python
print("مرحبًا بالعالم!")
```

هذا كل شيء — لا تحتاج فاصلة منقوطة، لا تحتاج أقواس معقّفة.

## المتغيّرات

```python
# تعريف المتغيّرات بلا نوع صريح
name = "عاصم"
age = 25
is_developer = True

# الطباعة
print(name)        # عاصم
print(name, age)   # عاصم 25
```

## أنواع البيانات

| النوع | مثال | الوصف |
|------|------|-------|
| `str` | `"نص"` | نص |
| `int` | `42` | عدد صحيح |
| `float` | `3.14` | عدد عشري |
| `bool` | `True` / `False` | منطقي |
| `list` | `[1, 2, 3]` | قائمة |
| `dict` | `{"name": "عاصم"}` | قاموس |

## الشروط

```python
age = 18

if age >= 18:
    print("بالغ")
elif age >= 13:
    print("مراهق")
else:
    print("طفل")
```

> لاحظ: المسافات (Indentation) مهمة جدًا في Python — بدل الأقواس.

## الحلقات

```python
# حلقة for
for i in range(5):
    print(i)
# 0 1 2 3 4

# المرور على قائمة
fruits = ["تفاح", "موز", "برتقال"]
for fruit in fruits:
    print(fruit)
```

## الدوال

```python
def greet(name):
    return f"مرحبًا {name}!"

print(greet("عالم تقني"))
# مرحبًا عالم تقني!
```

## القواميس (Dictionaries)

```python
person = {
    "name": "عاصم",
    "age": 25,
    "skills": ["HTML", "CSS", "Python"]
}

print(person["name"])
print(person["skills"][0])  # HTML
```

## مشروع عملي: حاسبة

```python
def calculator(a, b, operator):
    if operator == "+":
        return a + b
    elif operator == "-":
        return a - b
    elif operator == "*":
        return a * b
    elif operator == "/":
        return a / b if b != 0 else "خطأ: قسمة على صفر"
    else:
        return "عملية غير معروفة"

print(calculator(10, 5, "+"))  # 15
print(calculator(10, 0, "/"))  # خطأ: قسمة على صفر
```
