هل تريد موقعك الخاص دون دفع أي شيء؟ هذا الدليل العملي يأخذك خطوة بخطوة.

## المتطلّبات

- حساب GitHub مجاني (التسجيل من الهاتف ممكن)
- متصفح على هاتفك
- لا حاجة لأي خبرة برمجية متقدّمة!

## الخطوة 1: إنشاء حساب GitHub

1. افتح [github.com](https://github.com) على هاتفك
2. اضغط **Sign up**
3. أدخل بريدك وكلمة مرور قوية
4. تأكيد الحساب عبر البريد

## الخطوة 2: إنشاء مستودع جديد (Repository)

1. بعد تسجيل الدخول، اضغط زر **+** أعلى يسار
2. اختر **New repository**
3. سمّه باسم مميّز، مثل: `my-website`
4. اجعله **Public** (عام)
5. فعّل **Add a README file**
6. اضغط **Create repository**

> إذا سمّيت المستودع `username.github.io` (حيث username اسم حسابك)، فسيكون رابط موقعك `https://username.github.io` مباشرة!

## الخطوة 3: إنشاء ملف HTML

1. في صفحة المستودع، اضغط **Add file** → **Create new file**
2. سمّه `index.html`
3. الصق الكود التالي:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>موقعي الأول</title>
  <style>
    body {
      font-family: 'Tajawal', sans-serif;
      background: linear-gradient(135deg, #667eea, #764ba2);
      color: white;
      text-align: center;
      padding: 50px 20px;
      min-height: 100vh;
      margin: 0;
    }
    h1 { font-size: 2.5em; }
    a {
      color: white;
      background: rgba(255,255,255,0.2);
      padding: 10px 25px;
      border-radius: 30px;
      text-decoration: none;
      display: inline-block;
      margin-top: 20px;
    }
  </style>
</head>
<body>
  <h1>مرحبًا، أنا عاصم 👋</h1>
  <p>هذا موقعي الأول على الإنترنت!</p>
  <a href="https://wa.me/00967735383729">راسلني</a>
</body>
</html>
```

4. مرّر للأسفل واضغط **Commit changes**

## الخطوة 4: تفعيل GitHub Pages

1. اذهب لإعدادات المستودع: تبويب **Settings**
2. من القائمة الجانبية، اختر **Pages**
3. في قسم **Source**، اختر فرع `main`
4. اضغط **Save**

⏳ انتظر 1-2 دقيقة حتى يبني GitHub موقعك.

## الخطوة 5: زيارة موقعك! 🎉

رابط موقعك سيكون:
```
https://USERNAME.github.io/REPOSITORY-NAME/
```

أو إذا سمّيته `USERNAME.github.io`:
```
https://USERNAME.github.io/
```

## نصائح للتطوير

- **غيّر الألوان** في قسم `style` — جرّب أكواد ألوان مختلفة من [coolors.co](https://coolors.co)
- **أضف صورة**: استضفها على [imgur](https://imgur.com) وضع الرابط في `<img src="...">`
- **أضف صفحات**: أنشئ ملفات `about.html`, `contact.html` واربط بينها
- **استخدم قالبًا جاهزًا**: من [HTML5 UP](https://html5up.net) أو [Start Bootstrap](https://startbootstrap.com)

## ماذا بعد؟

بعد أن تنشئ موقعك الأول، تعلّم:
- **HTML و CSS** لتخصيص أفضل (شاهد شروحاتنا السابقة!)
- **Git** لإدارة التعديلات
- **Jekyll** للتحويل إلى مدونة حقيقية (هكذا بُني موقع عالم تقني!)

> البداية دائمًا أصعب خطوة. بعد أول موقع، يصبح الطريق أسهل بكثير.

نتمنى لك التوفيق! 🌐
