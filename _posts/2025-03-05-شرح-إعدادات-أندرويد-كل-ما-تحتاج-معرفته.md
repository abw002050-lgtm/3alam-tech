هاتفك الأندرويد يخفي ميزات قوية. هذا الشرح يأخذك من الأساسيات لإعدادات المطور المتقدمة.

## لماذا تفهم إعدادات أندرويد؟

- **تحكم كامل** بهاتفك
- **توفير بطارية وبيانات**
- **حل مشاكل** شائعة
- **وصول لميزات خفية**
- **تحسين الأداء**

## الأساسيات: الإعدادات اليومية

### 1. إدارة التطبيقات

**الطريقة:** الإعدادات → التطبيقات

| المهمة | ما تفعله |
|--------|---------|
| **تعطيل تطبيق** | اختر التطبيق → تعطيل (للتطبيقات الافتراضية المزعجة) |
| **إيقاف الإشعارات** | التطبيق → الإشعارات → إيقاف |
| **مسح البيانات** | التطبيق → تخزين → مسح البيانات (تحلّ مشاكل التطبيق) |
| **مسح الذاكرة المؤقتة** | التطبيق → تخزين → مسح الذاكرة المؤقتة |

> **معلومة:** "مسح البيانات" يعيد التطبيق لحالته الأولى — كأنك نزّلته للتو. حلّ رائع للمشاكل المستعصية.

### 2. توفير البطارية

**الطريقة:** الإعدادات → البطارية

- **وضع توفير الطاقة** — يقلّل أداء الخلفية
- **تقييد التطبيقات في الخلفية** — للتطبيقات التي لا تستخدمها كثيرًا
- **إيقاف الموقع** — أكبر مستهلك للبطارية

### 3. إدارة البيانات

**الإعدادات → الشبكة والإنترنت → استخدام البيانات**

- **ضبط حد البيانات** — ينبهك عند تجاوز الباقة
- **توفير البيانات** — يمنع التطبيقات من استخدام البيانات في الخلفية
- **بيانات الخلفية** — عطّلها للتطبيقات التي لا تحتاج تحديثًا مستمرًا

## إعدادات المطور — للمتقدمين

إعدادات المطور مخفية افتراضيًا. لتفعيلها:

### الخطوة 1: تفعيل خيارات المطور

1. الإعدادات → **حول الهاتف**
2. ابحث عن **رقم الإصدار** (أو Build Number)
3. اضغط عليه **7 مرات** متتالية
4. سترى رسالة "أنت الآن مطوّر!"

### الخطوة 2: الوصول لإعدادات المطور

الإعدادات → **النظام** → **خيارات المطور**

### أهم إعدادات المطور

| الإعداد | الفائدة |
|---------|---------|
| **USB Debugging** | يسمح بتوصيل الهاتف للحاسوب (ADB، نقل ملفات متقدم) |
| **مصادر وهمية للسماح** | يسمح بتثبيت تطبيقات APK |
| **تسريع الرسم بالأجهزة** | يحسّن أداء الألعاب |
| **حد العمليات الخلفية** | يحدد عدد التطبيقات في الذاكرة |
| **عرض اللمس** | يعرض نقطة عند اللمس (مفيد للتسجيل) |
| **مقياس الرسوم المتحركة** | 0.5x يجعل الهاتف أسرع بصريًا |

> **تحذير:** لا تفعّل "USB Debugging" إلا عند الحاجة. وإن فعلت، لا توصل هاتفك بحواسيب عامة.

## حلول للمشاكل الشائعة

### المشكلة: هاتف بطيء

**الحلول:**
1. اذهب للتطبيقات → عطّل ما لا تستخدم
2. خيارات المطور → حد العمليات الخلفية → 4 عمليات
3. أمسح الذاكرة المؤقتة للتطبيقات الثقيلة (Chrome, WhatsApp)
4. أعد تشغيل الهاتف أسبوعيًا

### المشكلة: بطارية تنفد بسرعة

**الحلول:**
1. الإعدادات → البطارية → تطبيق استخدام البطارية — اكتشف المذنب
2. عطّل الموقع للتطبيقات غير الضرورية
3. فعّل توفير الطاقة
4. قلّل سطوع الشاشة أو فعّل السطوع التلقائي

### المشكلة: لا مساحة كافية

**الحلول:**
1. الإعدادات → التخزين → امسح الذاكرة المؤقتة دفعة واحدة
2. استخدم تطبيق **Files by Google** للعثور على الملفات الكبيرة
3. انقل الصور لـ Google Photos (سحابة مجانية)
4. احذف تحديثات التطبيقات القديمة

## إعدادات أمان مهمة

### قفل الشاشة

**الإعدادات → الأمان → قفل الشاشة**

| الطريقة | الأمان | السرعة |
|---------|--------|--------|
| **النمط** | متوسط | سريع |
| **الرقم السري (PIN)** | عالٍ | متوسط |
| **كلمة المرور** | عالٍ جدًا | بطيء |
| **البصمة** | عالٍ | فوري |
| **الوجه** | متوسط | فوري |

> أنصح بـ **البصمة + PIN احتياطيًا**.

### تشفير الهاتف

الهواتف الحديثة مشفّرة افتراضيًا. للتحقق:
- الإعدادات → الأمان → التشفير وبيانات الاعتماد

### العثور على هاتفي

فعّل **Find My Device** من Google:
- [google.com/android/find](https://www.google.com/android/find)
- يتطلب تفعيل الموقع والإنترنت

## إعدادات WiFi متقدمة

### تفعيل WiFi تلقائيًا

الإعدادات → الشبكة → WiFi → تفضيلات WiFi
- **تفعيل WiFi تلقائيًا** — يفتح WiFi عند وصولك لمنطقة معروفة

### مشاركة WiFi عبر QR

1. اذهب لتفاصيل شبكة WiFi المتصلة
2. اضغط **مشاركة**
3. امسح QR بهاتف آخر

> اقرأ شرحنا عن [مولّد QR](/tawabeek/مولّد-qr/) لمعرفة كيفية إنشاء رموز QR خاصة بك.

## نسخ احتياطي تلقائي

**الإعدادات → Google → النسخ الاحتياطي**

فعّل:
- **نسخ احتياطي لتطبيقات Google** — تطبيقاتك وبياناتها
- **نسخ احتياطي للصور** — Google Photos
- **نسخ احتياطي للبيانات** — جهات الاتصال، الإعدادات

> عند شراء هاتف جديد، الدخول بحساب Google يعيد كل شيء تلقائيًا.
