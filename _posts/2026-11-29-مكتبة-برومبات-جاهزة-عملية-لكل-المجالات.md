> **تبحث عن برومبتات جاهزة للاستخدام مباشرة؟** هذه المكتبة تضم أكثر من 50 برومبتًا احترافيًا مصنّفًا حسب المجال — انسخ، عدّل التفاصيل بين الأقواس، واحصل على نتائج مذهلة فورًا.

بعد فهمك لأساسيات [فن كتابة البرومبت]({{ '/shuroohat/2026/11/28/فن-كتابة-البرومبت-Prompt-Engineering-دليل-عملي-بالأمثلة.html' | relative_url }})، هذه المكتبة تمنحك قوالب جاهزة عملية. كل ما عليك: استبدل ما بين `[أقواس]` بتفاصيلك.

## 📝 قسم الكتابة والمحتوى

### 1. كتابة مقال احترافي

```
أنت كاتب محتوى محترف. اكتب مقالًا عن "[الموضوع]" بطول 
[عدد] كلمة، موجّهًا لـ [الجمهور]. استخدم لغة [عربية فصيحة/
بسيطة]، واقسم المقال إلى:
1. مقدمة جذّابة بـ [سؤال/إحصائية/قصة]
2. [N] محاور رئيسية بأمثلة عملية
3. خلاصة + دعوة للتفاعل
تجنّب [المصطلحات المعقدة/التكرار/الطول المبالغ].
```

### 2. كتابة منشور سوشيال ميديا

```
اكتب [عدد] منشورات [فيسبوك/إنستغرام/تويتر] عن "[الموضوع]".
كل منشور:
- جملة افتتاحية جذّابة (Hook)
- محتوى مفيد موجز
- دعوة للإجراء (CTA)
- [3-5] هاشتاجات مناسبة
النبرة: [ودّية/احترافية/حماسية].
الطول: [قصير/متوسط].
```

### 3. كتابة إيميل احترافي

```
اكتب إيميلًا [رسميًا/ودّيًا] إلى [المستلم] بخصوص [الموضوع].
الهدف: [الهدف].
ابدأ بتحية مناسبة، اشرح الطلب بوضوح في [عدد] جمل، 
واختم بدعوة واضحة للإجراء (رد/اجتماع/تأكيد).
النبرة: [احترافية/ودّية/حازمة].
```

### 4. تحسين نص موجود

```
أنت محرّر لغوي محترف. راجع هذا النص وحسّنه:
[النص]
موضّحًا:
- أخطاء لغوية أو إملائية
- جمل غامضة وأعد صياغتها
- اقتراحات لتحسين الأسلوب والوضوح
قدّم النسخة المحسّنة كاملة في النهاية.
```

### 5. كتابة قصة قصيرة

```
أنت كاتب قصص موهوب. اكتب قصة قصيرة عن "[الموضوع/الفكرة]".
- الشخصيات: [وصف مختصر]
- المكان: [مكان]
- الزمن: [زمن]
- النهاية: [سعيدة/مفتوحة/مأساوية]
- الطول: [عدد] كلمة
- الأسلوب: [واقعي/خيالي/رومانسي]
```

## 📈 قسم التسويق والأعمال

### 6. خطة تسويقية

```
أنت مستشار تسويق محترف. ضع خطة تسويقية [شهرية/ربع سنوية] 
لمشروع [وصف المشروع] في [الموقع/السوق].
شمل:
- تحليل الجمهور المستهدف
- القنوات المناسبة (فيسبوك/إنستغرام/واتساب/تيك توك)
- المحتوى المقترح لكل قناة
- الميزانية التقديرية [مبلغ]
- مؤشرات قياس النجاح (KPIs)
قدّمها في جدول منظّم.
```

### 7. كتابة إعلان جذّاب

```
اكتب [عدد] إصدارات مختلفة من إعلان لـ [المنتج/الخدمة].
الجمهور: [وصف].
الميزة الرئيسية: [الميزة].
العرض: [العرض/الخصم].
لكل إصدار:
- عنوان لافت (Headline)
- نص جذّاب (Body)
- دعوة للإجراء (CTA)
النبرة: [حماسية/احترافية/عاطفية].
```

### 8. تحليل المنافسين

```
أنت محلل أعمال. حلّل المنافسين في مجال [المجال] في 
[السوق/المنطقة]:
- [المنافس 1]: نقاط القوة / نقاط الضعف
- [المنافس 2]: نقاط القوة / نقاط الضعف
- [المنافس 3]: نقاط القوة / نقاط الضعف
ثم اقترح:
- فرصة تنافسية لمشروعي
- ميزة فريدة يمكنني تقديمها
قدّم في جدول مقارنة.
```

### 9. دراسة جدوى مبسّطة

```
ضّع دراسة جدوى مبسّطة لمشروع [وصف المشروع]:
- التكاليف الأولية (تجهيزات، رخص، مواد)
- التكاليف التشغيلية الشهرية
- الإيرادات المتوقعة (3 سيناريوهات: متفائل/واقعي/متحفظ)
- نقطة التعادل
- العائد المتوقع خلال [مدة]
- المخاطر الرئيسية وكيفية التخفيف
```

### 10. استراتيجية محتوى

```
أنت خبير استراتيجية محتوى. ضع جدول محتوى لـ [مدة] 
لمشروع [وصف]:
- [عدد] منشورات أسبوعيًا
- تنوع: [معلوماتي/تفاعلي/ترويجي]
- موضوعات مقترحة لكل أسبوع
- أفضل أوقات النشر
- هاشتاجات لكل منشور
قدّم في جدول.
```

## 💻 قسم البرمجة والتقنية

### 11. شرح كود

```
أنت مبرمج خبير في [اللغة]. اشرح لي هذا الكود:
[code]
موضّحًا:
- الوظيفة العامة
- شرح كل سطر أو كتلة مهمة
- أي أخطاء أو تحسينات
- مثال على الاستخدام
```

### 12. كتابة كود من الصفر

```
اكتب كود [اللغة] يقوم بـ [الوظيفة]:
المتطلبات:
- [متطلب 1]
- [متطلب 2]
- [متطلب 3]
أضف تعليقات تشرح الكود، وتعامل مع الأخطاء (Error Handling).
قدّم مثال استخدام في النهاية.
```

### 13. تصحيح أخطاء (Debug)

```
هذا الكود به خطأ:
[code]
الخطأ: [وصف الخطأ أو رسالته].
ساعدني:
- ابحث عن سبب الخطأ
- اشرح المشكلة
- قدّم الكود المصحّح
- اشرح ما الذي تغيّر ولماذا
```

### 14. تحسين أداء كود

```
راجع هذا الكود وحسّن أداءه:
[code]
- ابحث عن بطء أو عدم كفاءة
- اقترح تحسينات (خوارزمية أفضل، تقليل حلقات، ذاكرة)
- قدّم النسخة المحسّنة
- قارن التعقيد الزمني قبل/بعد
```

### 15. شرح مفهوم برمجي

```
اشرح لي [المفهوم البرمجي] في [اللغة/الإطار] 
للمبتدئ تمامًا:
- ما هو ولماذا يُستخدم
- مثال بسيط عملي
- متى تستخدمه ومتى لا
- أخطاء شائعة في استخدامه
تجنّب المصطلحات المعقدة دون شرحها.
```

## 📚 قسم التعليم والدراسة

### 16. تلخيص درس

```
لخّص هذا الدرس في [عدد] نقاط رئيسية:
[النص/الدرس]
لكل نقطة:
- العنوان
- الشرح الموجز (جملتان)
- مثال إن أمكن
اختم بسؤال للمراجعة.
```

### 17. شرح مفهوم للمبتدئ

```
اشرح لي [المفهوم/الموضوع] كأني طالب [المرحلة] 
ولا أعرف شيئًا عنه:
- ابدأ بتعريف بسيط
- استخدم تشبيهًا من الحياة اليومية
- قسّم إلى خطوات
- مثال عملي
- سؤال للتحقق من فهمي
```

### 18. أسئلة اختبار

```
أنت معلم [المادة]. أنشئ [عدد] أسئلة اختبار عن [الموضوع]:
- [N] أسئلة اختيار من متعدد (4 خيارات)
- [N] أسئلة صح/خطأ
- [N] أسئلة مقالية قصيرة
قدّم الإجابات الصحيحة في النهاية مع شرح موجز.
المستوى: [سهل/متوسط/صعب].
```

### 19. خطة دراسة

```
ضع لي خطة دراسة لـ [المادة/الامتحان] خلال [مدة]:
- عدد ساعات الدراسة يوميًا: [عدد]
- أيام الدراسة: [أيام]
- تقسيم المواضيع على الأيام
- وقت للمراجعة والاختبار التجريبي
- نصائح للتركيز والحفظ
قدّم في جدول أسبوعي.
```

### 20. ترجمة وتعريب

```
ترجم هذا النص من [اللغة] إلى العربية بأسلوب:
[عربي فصيح/عربي بسيط/لهجة]
مع:
- دقة المعنى لا الحرفية
- مراعاة السياق الثقافي
- الحفاظ على النبرة الأصلية
[النص]
```

## 💼 قسم الإنتاجية والإدارة

### 21. تنظيم الوقت

```
أنت مدرب إنتاجية. نظّم لي يومي بناءً على:
- المهام: [قائمة المهام]
- الوقت المتاح: [من ساعة إلى ساعة]
- أولوياتي: [ما هو أهم]
- فترات الراحة: [كل كم ساعة]
قدّم جدولًا يوميًا واقعيًا مع نصائح للالتزام.
```

### 22. كتابة تقرير

```
اكتب تقريرًا [شهريًا/أسبوعيًا] عن [الموضوع/المشروع]:
شمل:
- ملخص تنفيذي (3 جمل)
- ما تم إنجازه
- التحديات
- الخطوات القادمة
- مؤشرات الأداء
النبرة: احترافية وموجزة.
الطول: [عدد] كلمة.
```

### 23. محضر اجتماع

```
نظّم محضر اجتماع بناءً على هذه الملاحظات:
[الملاحظات]
شمل:
- تاريخ ووقت الاجتماع
- الحضور
- النقاط المناقشة
- القرارات المتخذة
- المهام الموكلة (مع المسؤول والموعد)
- الاجتماع القادم
```

### 24. رسالة شكر

```
اكتب رسالة شكر [رسمية/ودّية] إلى [الشخص] بمناسبة [السبب].
النبرة: [دافئة/احترافية].
الطول: موجزة.
اذكر تفصيلًا محددًا يظهر صدق الشكر.
```

### 25. طلب وظيفي

```
اكتب رسالة طلب وظيفة لمنصب [المنصب] في [الشركة].
مؤهلاتي: [قائمة].
خبراتي: [قائمة].
لماذا هذه الشركة: [سبب].
النبرة: احترافية وواثقة.
الطول: [عدد] كلمة.
```

## 🎨 قسم الإبداع والأفكار

### 26. توليد أفكار

```
اقترح [عدد] أفكار لـ [الموضوع/المشروع] لـ [الجمهور].
لكل فكرة:
- العنوان
- وصف موجز (جملتان)
- لماذا قد تنجح
رتّبها من الأفضل للجيد.
```

### 27. حل مشكلة إبداعي

```
لديّ مشكلة: [وصف المشكلة].
اقترح [عدد] حلول إبداعية (خارج الصندوق).
لكل حل:
- الفكرة
- كيفية التنفيذ
- الميزة
- التحدي المحتمل
```

### 28. سيناريو/قصة تفاعلية

```
اكتب سيناريو تفاعلي عن [الموضوع]:
- الشخصية: [وصف]
- الموقف: [وصف]
- القرارات المحتملة (3 خيارات في كل مرحلة)
- عواقب كل اختيار
اجعله تعليميًا وممتعًا.
```

### 29. شعارات (Slogans)

```
اقترح [عدد] شعارًا إعلانيًا لـ [المنتج/العلامة].
الميزة: [الميزة].
الجمهور: [الجمهور].
لكل شعار:
- النص (قصير وجذّاب)
- الفكرة وراءه
رتّب الأفضل.
```

### 30. أفكار محتوى فيديو

```
اقترح [عدد] أفكار فيديو [يوتيوب/تيك توك/ريلز] عن 
[الموضوع]:
لكل فكرة:
- العنوان الجذّاب
- مدة الفيديو
- الفكرة العامة
- الـ Hook الأول (أول 3 ثوانٍ)
- دعوة للاشتراك/الإعجاب
```

## 🔧 قسم مهارات يومية

### 31. خطة توفير مالي

```
ضع لي خطة توفير [مبلغ] خلال [مدة]:
- دخلي الشهري: [مبلغ]
- مصاريفي الثابتة: [قائمة]
- مصاريفي المتغيرة: [تقدير]
اقترح:
- أين أقلّل
- كيف أزيد الدخل
- جدول ادخار واقعي
- نصائح للالتزام
```

### 32. قائمة تسوق ذكية

```
سوّق لي قائمة تسوق أسبوعية لمحل [وصف المنزل/الأسرة]:
- الميزانية: [مبلغ]
- عدد الأفراد: [عدد]
- تفضيلات: [وصف]
- تجنّب: [ما لا تريد]
رتّبها حسب الأقسام (خضار، بقالة، إلخ).
```

### 33. نصائح صحية

```
أنت مدرب صحة. ضع لي خطة [أكل/رياضة] بسيطة:
- عمري: [عمر]
- وزني: [وزن]
- هدفي: [هدف]
- وقت متاح للرياضة: [وقت]
- قيود صحية: [إن وُجد]
اقترح جدولًا أسبوعيًا واقعيًا.
```

### 34. تنظيم رحلة

```
خطّط لي رحلة إلى [مكان] خلال [مدة]:
- الميزانية: [مبلغ]
- عدد الأفراد: [عدد]
- الاهتمامات: [طبي/ثقافي/ترفيه]
شمل:
- جدول الأيام
- الأماكن المقترحة
- تقدير التكاليف
- نصائح محلية
```

### 35. تحسين سيرة ذاتية

```
أنت خبير موارد بشرية. راجع سيرتي الذاتية وحسّنها:
[السيرة]
- حسّن الصياغة
- أبرز الإنجازات
- اقترح إضافة أو حذف
- قدّم نسخة محسّنة
الهدف: التقدّم لمنصب [المنصب].
```

## ⚡ برومبتات متقدمة

### 36. تحليل بيانات

```
أنت محلل بيانات. حلّل هذه البيانات:
[البيانات/الجدول]
- ما الأنماط الواضحة؟
- ما الاتجاهات؟
- ما التوصيات؟
قدّم في تقرير موجز مع جدول ملخّص.
```

### 37. محاكاة مقابلة

```
أنت مسؤول توظيف. أجري معي مقابلة لوظيفة [المنصب]:
- اطرح [عدد] أسئلة (واحدة تلو الأخرى)
- انتظر إجابتي
- قيّم إجابتي بعد كل سؤال
- في النهاية، قدّم تقييمًا شاملًا ونصائح
```

### 38. تفكيك هدف

```
أريد تحقيق [الهدف] خلال [مدة].
فكّكه إلى:
- أهداف فرعية (مرحلية)
- خطوات عملية لكل هدف
- مؤشرات التقدّم
- عقبات محتملة وحلول
- جدول زمني
قدّم في جدول.
```

### 39. مراجعة عقد

```
أنت مستشار قانوني. راجع هذا العقد وأشر إلى:
[نص العقد]
- البنود التي تضرني
- البنود الغامضة
- ما ينقص العقد
- توصيات للتعديل
(هذا للفهم فقط — استشر محاميًا للقرارات النهائية)
```

### 40. تلخيص كتاب

```
لخّص كتاب "[عنوان الكتاب]" للمؤلف [المؤلف]:
- الفكرة الرئيسية (3 جمل)
- [N] نقاط مفصلية
- اقتباسات مهمة
- كيف أطبّق أفكاره في حياتي
الطول: [عدد] كلمة.
```

## 🎯 برومبتات خاصة بالسياق العربي/اليمني

### 41. محتوى للسوق اليمني

```
اكتب [نوع المحتوى] موجّهًا للجمهور اليمني عن [الموضوع]:
- استخدم أمثلة من الواقع اليمني
- اذكر عملات محلية (ريال/ريال سعودي/دولار)
- راعِ البنية التحتية (إنترنت/كهرباء)
- النبرة: [محترمة/ودّية]
- تجنّب [ما تريد]
```

### 42. ترجمة مع تكييف ثقافي

```
ترجم هذا النص من الإنجليزية للعربية، لكن:
- ليست ترجمة حرفية
- كيّف الأمثلة للسياق العربي/اليمني
- استبدل التعبيرات الثقافية بما يناسب القارئ العربي
- احفظ المعنى والهدف
[النص]
```

### 43. شرح تقني للمبتدئ اليمني

```
اشرح [المفهوم التقني] لشخص يمني مبتدئ تمامًا:
- لا تفترض معرفة تقنية سابقة
- استخدم تشبيهات من البيئة اليمنية
- اربط بفوائد عملية له
- تجنّب المصطلحات الإنجليزية دون شرح
```
