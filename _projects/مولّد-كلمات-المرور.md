## نظرة عامة

تطبيق **مولّد كلمات المرور** ينتج كلمات مرور قوية وعشوائية لحماية حساباتك. كل كلمة مرور تُولّد محليًا على جهازك — لا تُرسل لأي خادم.

## المزايا

- 🔐 توليد كلمات مرور حتى 64 حرفًا
- 🔀 خيارات: أحرف كبيرة/صغيرة، أرقام، رموز
- 📋 نسخ بضغطة واحدة
- 🔒 آمن بالكامل — يعمل دون إنترنت
- 📱 واجهة سهلة على الهاتف

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| HTML5 | الواجهة |
| CSS3 | التصميم |
| JavaScript | منطق التوليد |
| Web Crypto API | عشوائية آمنة |

## كيفية الاستخدام

1. اختر طول كلمة المرور (8-64)
2. فعّل الخيارات: أحرف كبيرة، أرقام، رموز
3. اضغط **توليد**
4. اضغط **نسخ** لنسخ كلمة المرور

## لقطة من الكود

```javascript
function generatePassword(length, options) {
  const chars = {
    lower: "abcdefghijklmnopqrstuvwxyz",
    upper: "ABCDEFGHIJKLMNOPQRSTUVWXYZ",
    numbers: "0123456789",
    symbols: "!@#$%^&*()_+-=[]{}|;:,.<>?"
  };

  let pool = "";
  if (options.lower) pool += chars.lower;
  if (options.upper) pool += chars.upper;
  if (options.numbers) pool += chars.numbers;
  if (options.symbols) pool += chars.symbols;

  let password = "";
  const array = new Uint32Array(length);
  crypto.getRandomValues(array);

  for (let i = 0; i < length; i++) {
    password += pool[array[i] % pool.length];
  }
  return password;
}

console.log(generatePassword(16, {lower:true, upper:true, numbers:true, symbols:true}));
// مثال: "K9#mP2$xL7@nQ4^w"
```

## نصائح لكلمات مرور آمنة

- استخدم 16 حرفًا على الأقل
- ادمج أحرف كبيرة وصغيرة وأرقام ورموز
- لا تُعِد استخدام نفس كلمة المرور في موقعين
- استخدم مدير كلمات مرور (Bitwarden, 1Password)
