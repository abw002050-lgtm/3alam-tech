## نظرة عامة

تطبيق **محوّل العملات** يحوّل بين العملات الرئيسية بسرعة. مبني على JavaScript وواجهة متجاوبة تعمل على الهاتف والحاسوب.

## المزايا

- 💱 دعم عملات متعددة (ريال يمني، دولار، يورو، ريال سعودي)
- ⚡ تحويل فوري عند الكتابة
- 📱 تصميم متجاوب للهاتف
- 🌙 وضع ليلي/نهاري
- 🔄 تبديل سريع بين العملتين

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| HTML5 | الهيكل |
| CSS3 | التصميم المتجاوب |
| JavaScript | منطق التحويل |
| ExchangeRate API | أسعار العملات |

## كيفية الاستخدام

1. اختر العملة المصدر
2. اختر العملة الهدف
3. أدخل المبلغ
4. تظهر النتيجة فورًا

## لقطة من الكود

```javascript
async function convert(amount, from, to) {
  const response = await fetch(
    `https://api.exchangerate.com/latest?base=${from}`
  );
  const data = await response.json();
  const rate = data.rates[to];
  return amount * rate;
}

convert(100, "USD", "YER").then(result => {
  console.log(`100 دولار = ${result} ريال يمني`);
});
```
