## نظرة عامة

تطبيق **حاسبة تقنية** هو تطبيق ويب بسيط يقدّم عمليات حسابية أساسية بواجهة عصرية وسهلة الاستخدام.

## المزايا

- ✅ عمليات حسابية أساسية (جمع، طرح، ضرب، قسمة)
- ✅ دعم النسب المئوية
- ✅ تصميم متجاوب يعمل على الهاتف والحاسوب
- ✅ وضع ليلي/نهاري

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| HTML5 | الهيكل |
| CSS3 | التصميم |
| JavaScript | المنطق |

## كيفية الاستخدام

1. افتح التطبيق من المتصفح
2. اكتب الأرقام باستخدام الأزرار
3. اضغط `=` لعرض النتيجة

> ملاحظة: هذا تطبيق تجريبي لتوضيح كيفية نشر التطبيقات على المنصة.

## لقطة من الكود

```javascript
function calculate(a, b, operator) {
  switch(operator) {
    case '+': return a + b;
    case '-': return a - b;
    case '*': return a * b;
    case '/': return b !== 0 ? a / b : 'خطأ';
  }
}
```
