## نظرة عامة

تطبيق **قائمة المهام** يساعدك على تنظيم يومك — أضف، أكمِل، واحذف المهام. كل البيانات تُحفظ محليًا في المتصفح (localStorage)، فلا تحتاج تسجيل دخول.

## المزايا

- ✅ أضف مهمة جديدة بسرعة
- ✔️ حدّد المهام كمكتملة
- 🗑️ احذف المهام المنجزة
- 💾 حفظ تلقائي في المتصفح
- 📱 يعمل على الهاتف والحاسوب
- 🌙 وضع ليلي

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| HTML5 | الهيكل |
| CSS3 | التصميم |
| JavaScript | المنطق والتفاعل |
| localStorage | حفظ البيانات |

## كيفية الاستخدام

1. اكتب مهمتك في الحقل العلوي
2. اضغط Enter أو زر **+**
3. اضغط على المهمة عند إنجازها
4. اضغط على × لحذفها

## لقطة من الكود

```javascript
// حفظ المهام في المتصفح
function saveTasks(tasks) {
  localStorage.setItem("tasks", JSON.stringify(tasks));
}

// استرجاع المهام
function loadTasks() {
  const saved = localStorage.getItem("tasks");
  return saved ? JSON.parse(saved) : [];
}

// إضافة مهمة جديدة
function addTask(text) {
  const tasks = loadTasks();
  tasks.push({
    id: Date.now(),
    text: text,
    completed: false
  });
  saveTasks(tasks);
  render();
}

// عرض القائمة
function render() {
  const tasks = loadTasks();
  const list = document.getElementById("task-list");
  list.innerHTML = tasks.map(task => `
    <li class="${task.completed ? 'done' : ''}">
      <span onclick="toggle(${task.id})">${task.text}</span>
      <button onclick="remove(${task.id})">×</button>
    </li>
  `).join("");
}
```

- تُسهّل ترتيب الأولويات
